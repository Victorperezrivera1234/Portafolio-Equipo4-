# CircuitoDeJuegoDeLEDsConBuzzer

Dentro de este carpeta está la lista detallada de todos los componentes utilizados para la construcción de este proyecto. Además, dentro de esta carpeta también esta el código actualizado, las conexiones utilizadas para construir el circuito, las pruebas de funcionamiento y el reporte general del proyecto. El objetivo de este circuito es el mismo que el CircuitoJuegoDeLEDsV1, pero esta vez tiene un buzzer pasivo implementado para indicar que el jugador ha presionado el botón correcto para el LED activamente encendido. Además, se agregó un sistema de "time out" en donde, si el usuario no presiona un boton despues de 5 segundos que un nuevo LED se prende, el juego se termina. Esta condición solo se activa despues de que el primer boton haya sido presionado correctamente.
