# CircuitoDeJuegoDeLEDsConBuzzer

Dentro de este carpeta esta la lista detallada de todos los componentes utilizados para la construcción del circuito. Además, dentro de esta carpeta también esta el código actualizado, las conexiones utilizadas para construir el circuito, las pruebas de funcionamiento y el reporte general del proyecto. El objetivo de este circuito era el mismo que el CircuitoJuegoDeLEDsV1, pero esta vez tiene un buzzer pasivo implementado para indicar que el jugador ha presionado el botón correspondiente.
