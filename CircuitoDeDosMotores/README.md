# CircuitoDeDosMotores
El objetivo de este circuito es controlar dos motores de corriente directa mediante un Arduino y un controlador L293D. El sistema permite controlar de manera independiente la dirección y la velocidad de los motores mediante señales digitales y PWM. Durante la prueba de funcionamiento, se verifica el avance, retroceso y movimiento de los motores en direcciones opuestas utilizando diferentes velocidades.

Dentro de esta carpeta se encuentran los archivos correspondientes al proyecto:

- Reporte del circuito: documentación del desarrollo, funcionamiento y aprendizajes obtenidos.
- Esquemática: representación de las conexiones realizadas entre el Arduino, el L293D, los motores y la fuente de alimentación externa.
- Prueba de funcionamiento: evidencia del funcionamiento del circuito y de las diferentes fases programadas.
- Código: programa utilizado para controlar la dirección y velocidad de los motores.
